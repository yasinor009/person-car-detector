# اصلاح تشخیص دوربین موبایل زمینی

پیش‌فرض اجرا از مدل هوایی به YOLO26n عمومی COCO تغییر کرد. YOLO26s برای
balanced و long-range ارائه می‌شود. این‌ها وزن منتشرشده‌اند، آموزش اختصاصی نیسان نیستند.
فایل download_optional_model.py و لانچر start_aerial.bat حذف شدند؛ تاریخچه قابل بازیابی است.
پروفایل هوایی از اجرای فعلی حذف شد؛ گزارش‌های تاریخی حفظ شده‌اند.

خطای قابل بازتولید: در نگاشت قبلی فقط COCO person=0 و car=2 پذیرفته می‌شد.
وانت ممکن است truck=7 باشد و حتی با confidence بالا حذف شود. اکنون اجرای موبایل
و CLI متریک، car/truck را در خروجی car گروه‌بندی می‌کنند. model_class_id اصلی
در API باقی می‌ماند. این نگاشت همه کامیون‌ها را هم شامل می‌شود؛ pickup-only نیست.
اتوبوس، موتورسیکلت و دوچرخه همچنان وارد خروجی نمی‌شوند. برای ارزیابی passenger-car
استاندارد از --passenger-cars-only استفاده کنید؛ اعداد قدیمی قابل مقایسه مستقیم نیستند.

main.py اکنون از موتور قرارداددار جدید با threshold=.25 استفاده می‌کند؛ مسیر
قدیمی گوشی با کف پنهان .55 و مدل متفاوت از پیش‌فرض خارج شد. تأیید سه‌فریم
همچنان برقرار است. فایل تنظیمات برای مدل/پروفایل/منبع/معنای کلاس جدا می‌شود.

## آزمایش واقعی مدل، بدون ادعای پذیرش

تصویر عمومی زمینی:
https://raw.githubusercontent.com/pjreddie/darknet/master/data/dog.jpg

روی تصویر شامل وانت، سگ و دوچرخه، با threshold=.25 و ورودی 640:

| مدل | فقط car | car + truck |
|---|---|---|
| YOLO26n | بدون خروجی | یک car با model_class_id=7 و confidence=0.7607 |
| YOLO26s | یک car با confidence=0.6759 | همان car |

روی تصویر عمومی bus.jpg از Ultralytics، هر مدل چهار person گزارش کرد؛
confidence مدل n: .855/.845/.837/.557 و s: .926/.915/.867/.841.
اتوبوس به خودرو بازبرچسب‌گذاری نشد. این دو تصویر نه دیتاست پذیرش‌اند نه تصویر
نیسان کاربر، و برچسب فاصله ندارند. هیچ ادعای تشخیص ۵ یا ۱۰۰ متر از آن‌ها نمی‌شود.

راستی‌آزمایی نهایی: 106 تست موفق در 6.55 ثانیه، یک هشدار افزونه pytest.
اجرای واقعی `main.py --browser-camera` و ارسال JPEG وانت از HTTP هم انجام شد:
مدل ready، threshold=.25، خروجی car با model_class_id=7، confidence=.761 و track_id=1.
این تست مسیر نرم‌افزاری مرورگر را روی Linux بررسی می‌کند؛ بنچمارک خود Android نیست.

## اجرای گوشی پس از دریافت نسخه جدید

```sh
bash install_termux.sh
python main.py --browser-camera
```

مرورگر همان گوشی: http://127.0.0.1:5000 ، اجازه دوربین پشتی را بدهید.
اگر install_termux به‌علت نبود بسته سازگار Android شکست خورد، همان خطا باید
بررسی شود؛ wheel لینوکس جایگزین Android نیست. این نصب در محیط گوشی آزموده نشده.

اهداف دور (پر‌هزینه‌تر روی CPU):

```sh
python main.py --browser-camera --profile long-range
```

این مسیر مدل s با ورودی 1280 و برش پیکسلی دارد؛ تعداد FPS گوشی و تشخیص ۱۰۰ متر
تضمین نشده. رزولوشن واقعی، نور، لرزش و تعداد پیکسل هدف تعیین‌کننده‌اند.
برای عیب‌یابی مورد نیسان، تصویر اصلی همان دوربین با کادر کامل خودرو و
خروجی diagnostics مدل لازم است. فاصله هندسی همچنان به کالیبراسیون و دوربین ثابت نیاز دارد.
