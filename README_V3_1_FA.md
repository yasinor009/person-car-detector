## اجرا

```bash
bash install_termux.sh
python main.py --browser-camera
```

برای مدل بزرگ‌تر، همان گزینهٔ قبلی برقرار است:

```bash
python main.py --browser-camera --model models/person_car_yolo11s.onnx
```

هر دو وزن داخل بسته هستند. نصب PyTorch یا SciPy روی گوشی لازم نیست. دسترس‌پذیری بسته‌های Termux باید روی گوشی بررسی شود؛ این ارتقا روی دستگاه واقعی Android آزمایش نشده است.

## تفاوت‌های نسخهٔ ۳٫۱

- فقط انسان و خودروی سواری نمایش داده می‌شوند. برای مسیر تازه سه مشاهدهٔ قوی پیاپی لازم است.
- Kalman در فضای مرکز/عرض/ارتفاع و تخصیص دقیق Hungarian به‌جای انتخاب حریصانه، برای تطبیق استفاده می‌شوند.
- مسیر تأییدشده پس از حداکثر دو فریم عدم مشاهده می‌تواند با همان شناسه برگردد؛ در فریم گم‌شده هیچ کادری نمایش داده نمی‌شود و فاصله معتبر نیست. عمر زمانی هم محدود است: حدود یک ثانیه، با افزایش متناسب با زمان استنتاج کند.
- مشاهدات ضعیف بین ۰٫۲۵ و آستانهٔ قوی، فقط برای به‌روزرسانی داخلی مسیر تأییدشده استفاده می‌شوند؛ تشخیص نمایش‌داده‌شده یا هدف تازه نمی‌سازند. نبود مشاهدهٔ قوی به مدت طولانی باعث حذف مسیر می‌شود، حتی اگر مشاهدات ضعیف ادامه یابند.
- فاصله از عرض **مشاهده‌شدهٔ فعلی** محاسبه می‌شود؛ عرض پیش‌بینی‌شدهٔ Kalman برای فاصله استفاده نمی‌شود. بعد از گم‌شدن، تاریخچهٔ عرض پاک می‌شود تا اندازه‌های قدیمی وارد نتیجه نشوند.
- در رابط، حساسیت تقریبی به خطای فرضی دو پیکسل نشان داده می‌شود؛ این درصد خطای کل یا بازهٔ اطمینان فاصله نیست.
- کالیبراسیون لنز، عکس‌های پرت و تنوع ناکافی وضعیت صفحه را بررسی می‌کند. حدود کنترل کیفیت، پیش‌فرض مهندسی‌اند و صحت متری را تضمین نمی‌کنند.

## اهداف کوچک، اختیاری و پرهزینه

بر پایهٔ SAHI، تصویر کامل به‌علاوهٔ چهار برش هم‌پوشان پردازش می‌شود:

```bash
PERSON_CAR_TILED=1 python main.py --browser-camera
```

این حالت روی گوشی پیش‌فرض خاموش است؛ تقریباً پنج بار اجرای شبکه لازم دارد. در نمونه‌های محدود این جلسه افزایش تعداد اهداف صحیحِ اثبات‌شده دیده نشد و هزینهٔ استنتاج بیشتر شد. فقط پس از ارزیابی روی صحنهٔ اهداف کوچک آن را روشن کن. ممکن است خطای کاذب را هم افزایش دهد. کادر بریده‌شده در مرز داخلی برش پذیرفته نمی‌شود تا عرض ناقص وارد فاصله نشود.

## کالیبراسیون چندفاصله‌ای

فرمت قبلی `samples.json` معتبر است. برای هر مشاهده می‌توان انحراف معیار اندازه‌گیری پیکسل را اضافه کرد:

```json
{"known_width_m":0.5,"known_distance_m":3,"observed_width_px":150,"frame_width_px":640,"observed_width_std_px":2.0}
```

این تنها یک نمونهٔ فرم است؛ فایل کامل باید حداقل پنج مشاهدهٔ مستقل و سازگار داشته باشد. اندازهٔ مرجع و فاصله‌ها باید واقعاً اندازه‌گیری شده باشند. بعد از بستن برنامه:

```bash
python calibrate_multiview.py samples.json
python calibrate_multiview.py samples.json --apply
```

برازش جدید در فضای پیکسل، سهم نسبی اندازه‌گیری‌های نزدیک و دور را با توجه به نویز پیکسلی در نظر می‌گیرد. فرض خطای پیکسل، خطای سیستماتیک ابعاد جسم و زاویه را رفع نمی‌کند. ابزار لنز همان فرمان قبلی را دارد؛ عکس‌های بیشتر با زاویه، محل و اندازهٔ متفاوت لازم است. پس از اصلاح لنز، کالیبراسیون فاصله را تکرار کن.

## انتخاب آستانه برای کاهش خروجی کاذب

در validation، تصاویر فاقد انسان/خودرو از همان دیوارها و پس‌زمینه‌های محل را با برچسب خالی اضافه کن؛ تمام اهداف مثبت باید صحیح برچسب بخورند:

```bash
python evaluate_detector.py --dataset validation_set --sweep --objective precision --min-recall 0.50 --output threshold_report.json
python evaluate_detector.py --dataset separate_test_set --conf 0.70 --output test_report.json
```

عدد ۰٫۷۰ در فرمان دوم فقط مثال است؛ عدد انتخاب‌شدهٔ گزارش validation را قرار بده. انتخاب پیش‌فرض، بیشترین کران پایین Wilson برای precision بین آستانه‌هایی است که حداقل recall خواسته‌شده را برآورده کنند. اگر هیچ آستانه‌ای آن را برآورده نکند، ابزار خطا می‌دهد؛ نتیجهٔ بهینه جعل نمی‌شود. با `--objective f1` رفتار انتخاب بر اساس F1 در دسترس است.

برای بررسی مدل بزرگ‌تر یا برش‌ها:

```bash
python evaluate_detector.py --dataset validation_set --model models/person_car_yolo11s.onnx --tiled --sweep
```

کلاس‌ها باید COCO باشند: انسان صفر، خودرو دو. نتایج شامل precision/recall هر کلاس و نرخ تصاویر منفیِ دارای خروجی کاذب است. اگر یکی از کلاس‌ها در مجموعه وجود نداشته باشد، برای آن کلاس نتیجهٔ معتبر تعمیم‌پذیر نداریم. انتخاب آستانه خودکار روی تنظیمات برنامه اعمال نمی‌شود؛ آستانهٔ نهایی را پس از ارزیابی در رابط ثبت کن. این ارزیابی تصویر مستقل، کیفیت ردیابی ویدئو را نمی‌سنجد.
