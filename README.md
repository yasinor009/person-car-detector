# تشخیص انسان و خودرو

برنامه محلی Python برای تشخیص فقط دو کلاس `person` و `car`، ردیابی اهداف و
تخمین تقریبی فاصله با دوربین کالیبره‌شده. مدل‌های موجود عمومی هستند؛ دقت
تشخیص یا فاصله تا ۱۰۰ متر روی دوربین گوشی شما هنوز با داده میدانی تأیید نشده است.

## اجرای Termux

نسخه Termux را از F-Droid نصب کنید، سپس از ریشه پروژه:

```bash
bash install_termux.sh
python main.py --browser-camera
```

در مرورگر همان گوشی باز کنید:

```text
http://127.0.0.1:5000
```

اجازه دوربین پشتی را بدهید. اگر پورت اشغال بود:

```bash
python main.py --browser-camera --port 5001
```

و آدرس `http://127.0.0.1:5001` را باز کنید.

## اجرای لپ‌تاپ

Windows:

```text
install_laptop.bat
start_laptop.bat
```

Linux:

```bash
bash install_laptop.sh
.venv/bin/python run_laptop.py --profile balanced
```

پروفایل `cpu` سبک‌تر است. پروفایل `long-range` از مدل عمومی بزرگ‌تر،
ورودی ۱۲۸۰ و برش تصویر استفاده می‌کند و روی CPU کندتر است:

```bash
python run_laptop.py --profile long-range
```

## کالیبراسیون و فاصله

در داشبورد گوشی، «ثبت تصویر مرجع از دوربین» را بزنید؛ روی تصویر ثابت دور
تمام جسم مرجع کادر بکشید، عرض واقعی و فاصله اندازه‌گیری‌شده همان جسم را وارد
کنید و «ذخیره کالیبراسیون» را بزنید. این روش به تشخیص مدل وابسته نیست و
کادر مرجع به‌عنوان تشخیص انسان/خودرو ثبت نمی‌شود. فاصله واردشده باید واقعاً
اندازه‌گیری شده باشد؛ از فاصله حدسی استفاده نکنید. پس از تغییر لنز یا زوم
دوباره کالیبره کنید. برای اندازه‌گیری زنده، روی کادر تشخیص هدف بزنید و عرض
واقعی همان هدف را ثبت کنید. کالیبراسیون به‌تنهایی اندازه اهداف دیگر را تعیین نمی‌کند.

`calibrate_lens.py` اعوجاج لنز را کالیبره می‌کند و
`calibrate_multiview.py` فاصله کانونی را از چند اندازه‌گیری مرجع برازش می‌دهد.
فاصله تک‌دوربینه به اندازه واقعی هدف، زاویه، کادر تشخیص و کالیبراسیون وابسته است.
در وضعیت نامعتبر برنامه باید فاصله را نامشخص نمایش دهد.

## تشخیص در شب و اهداف کوچک

دکمه «حساسیت بیشتر برای شب / هدف دور» آستانه را روی ۰٫۲۵ می‌گذارد و
برش تصویر را فعال می‌کند. این حالت تا پنج بار اجرای مدل برای هر فریم نیاز دارد؛
اگر گوشی کند شد، «برش برای اهداف کوچک» را خاموش و تنظیمات را ذخیره کنید.
آستانه قابل تنظیم است و دیگر کف پنهان ۰٫۵۵ ندارد. آستانه پایین‌تر می‌تواند
خطای مثبت بیشتری ایجاد کند. سه فریم تأیید لازم است؛ روی گوشی کند، نمایش
اولین کادر ممکن است زمان ببرد. پیام پایین دوربین وضعیت ارسال JPEG را نشان می‌دهد.
اگر ارسال تصویر برقرار است ولی پردازش متوقف مانده، تعداد فریم و زمان استنتاج
را در بالای صفحه بررسی کنید. پس از دریافت نسخه جدید صفحه مرورگر را تازه کنید.

## آموزش و ارزیابی

- `train_two_class.py`: آموزش اختصاصی person/car
- `evaluate_detector.py` و `evaluate_laptop.py`: Precision، Recall و F1
- `tune_laptop.py`: تنظیم آستانه روی validation
- `tests/`: آزمون‌های نرم‌افزاری
- `models/PROVENANCE_V4.json`: منشأ، قرارداد و مجوز مدل‌ها

داده آموزش، validation و test باید بر اساس ویدئو/محل جدا شوند. خروجی confidence
مدل معادل دقت اندازه‌گیری‌شده نیست.
