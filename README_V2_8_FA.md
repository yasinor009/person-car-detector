# نسخه ۲.۸ — گزارش اصلاحات

این نسخه از پروژه ۲.۷ ساخته شده و تغییرات زیر را دارد:

- کالیبراسیون از کادرهای منبع `motion` و `thermal` رد می‌شود، چون ماسک حرکت ممکن است فقط بخشی از جسم را بپوشاند.
- کالیبراسیون وقتی ردیابی `reacquiring` یا `lost` است رد می‌شود.
- برای کالیبراسیون فقط پنج عرض اخیر بررسی می‌شوند؛ اگر پراکندگی p10 تا p90 از ۱۲٪ بیشتر باشد، کالیبراسیون ذخیره نمی‌شود.
- عرض واقعی فریم هنگام کالیبراسیون ذخیره می‌شود و هنگام تغییر عرض فریم، فاصله کانونی مؤثر متناسب‌سازی می‌شود.
- سه نمونه پایدار اخیر می‌توانند برای کاهش لرزش عرض کادر استفاده شوند؛ تغییر محسوس اندازه هدف باعث می‌شود اندازه فعلی استفاده شود.
- مختصات YOLO پس از letterbox با مقیاس واقعی افقی و عمودی نگاشت می‌شوند تا خطای ناشی از گردکردن ابعاد کاهش یابد.
- تست‌های جدید برای کالیبراسیون ناپایدار، کادر ماسک حرکت، استفاده از نمونه‌های اخیر و تغییر عرض فریم افزوده شده‌اند.

## آزمون

`python -m pytest -q` → `40 passed` در محیط ساخت.

## محدودیت

این تغییرات نرم‌افزاری و کالیبراسیون را بهبود می‌دهند؛ وزن مدل ONNX در این نسخه بازآموزی نشده است. تأیید دقت تشخیص نیازمند مجموعه مستقل تصاویر/ویدئوهای برچسب‌خورده از دوربین واقعی است. تخمین فاصله تک‌دوربینه نیز بدون عرض واقعی هدف و کادر کامل جسم، فاصله متریک قابل اتکا تولید نمی‌کند.
